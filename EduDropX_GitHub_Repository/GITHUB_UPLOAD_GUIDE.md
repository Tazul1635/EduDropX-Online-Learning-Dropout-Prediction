# Upload this repository to GitHub

1. Download `EduDropX_GitHub_Repository.zip` and extract it on your computer.
2. On GitHub, create a new empty repository named `EduDropX-Online-Learning-Dropout-Prediction`. Choose **Public** only if the journal requires public access and the materials in the repository are approved for public release.
3. Do not select GitHub's options to add a README, `.gitignore`, or license; this package already contains the project README and ignore rules.
4. Open the extracted `EduDropX_GitHub_Repository` folder. Upload the **contents inside that folder** (including hidden files such as `.gitignore`) to the root of the new GitHub repository. Do not upload only the ZIP file.
5. Use a commit message such as `Add EduDropX reproducibility materials` and commit the upload.
6. Open the repository page and check that `README.md`, `notebooks/`, `docs/`, `data/`, `requirements.txt`, and `.gitignore` are visible.

## Before making the repository public

- Confirm that the dataset access and privacy statement matches the actual consent and ethics approvals. The raw CSV is not included in this package and is ignored by Git.
- Update `CITATION.cff` and the README with the final authors, repository URL, journal citation, and DOI when available.
- Select and add a code license only after all authors and the relevant institution agree. No license is assigned in this package.
- Check the journal's policy for public code repositories during double-blind review. Some journals require an anonymized repository or a private reviewer link.
